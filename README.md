Udaan — Nepal-first AI education & opportunity navigator (website-first, Next.js/TypeScript/Postgres)

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

This repository contains the complete Udaan platform for Nepal students:
- Public opportunity discovery (scholarships, colleges, courses, admissions, careers)
- Student profile management and matching engine
- Application tracker with deadline reminders
- AI Advisor for personalized recommendations
- Admin CMS for verification and content management

**Phase 1 - Project Setup**
- Repository scaffold with Next.js, TypeScript, Tailwind, Prisma
- Design tokens implemented (colors, typography, spacing)
- CI pipeline configured
- Environment separation (local/preview/prod)

**Next Steps**
Follow the roadmaps in `/docs/` to build the full platform:
- Phase 2: Core UI components (OpportunityCard, MatchScoreBadge, etc.)
- Phase 3: Authentication with Auth.js
- Phase 4: Backend / Database setup
- Phase 5: Core features (profile, matching, advisor, admin CMS)
